## 2026-06-03 - Removed CEO Bypass Backdoor\n**Vulnerability:** A hardcoded backdoor (CEO Bypass Key) allowed arbitrary users to bypass Clerk authentication, API rate limits, and paywalls by simply setting an `ayura_ceo_token` cookie.\n**Learning:** Hardcoded backdoor keys used for testing or administrative bypasses often end up in production, creating critical privilege escalation vectors and exposing AI systems to unmetered abuse.\n**Prevention:** Never implement static bypass keys in authentication or rate-limiting logic. Administrative access should rely on standard Role-Based Access Control (RBAC) mechanisms with proper auditing.
