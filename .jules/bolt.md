## 2024-05-24 - React-Three-Fiber BufferAttribute Reallocation\n**Learning:** Passing a new array reference or dynamically creating typed arrays (e.g., `new Float32Array(...)`) inside the `args` prop of a `<bufferAttribute>` in `@react-three/fiber` triggers costly WebGL buffer reallocations on every render. Additionally, instantiating intermediate 3D objects like `THREE.Vector3` inside iteration loops just to extract primitive coordinates causes unnecessary memory allocation and garbage collection overhead.\n**Action:** Fully memoize typed arrays and pass the stable reference to `args`. Avoid creating intermediate 3D objects inside loops when preparing flat coordinate arrays by directly pushing or spreading primitive coordinate values.
