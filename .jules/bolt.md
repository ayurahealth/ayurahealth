## 2024-05-19 - ReactMarkdown Component Prop Identity Learning
**Learning:** In the `ClinicalMarkdown.tsx` component, the `components` prop is an inline object defined directly inside the component body. This causes the `components` object to be recreated on every render of `ClinicalMarkdown`. Since `ReactMarkdown` treats a new `components` object reference as a prop change, it forces an unmount and remount of the entire markdown DOM tree instead of updating it, leading to significant performance degradation (especially in chat interfaces where markdown content streams or updates frequently). This codebase explicitly forbids passing inline object to the `components` prop of `react-markdown`.
**Action:** Always extract the `components` object to a static variable outside the component or wrap it in a `useMemo` hook to maintain referential equality across renders when working with `ReactMarkdown`.
